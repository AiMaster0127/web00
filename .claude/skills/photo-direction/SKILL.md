# フォトディレクション

**素材の質が、デザインの上限を決めます。**
どれだけ組版と配色を磨いても、写真が悪ければそこで頭打ちです。逆に、写真がいいだけでデザインは半分成立します。

だから、デザインを始める前に素材の話を終わらせてください。

## 最初に確認すること（見積り前）

**「いい感じの写真を入れておいて」は、素材支給なしの意味です。** ほぼ確実に。

見積り段階で握ります。
- 写真はあるか（あり / なし / 一部）
- ロゴのデータ形式（ai / svg / png / 「名刺しかない」）
- ないなら、フリー素材で妥協するか、撮影するか、**誰が費用を持つか**

ここを曖昧にしたまま着手すると、無償の素材探しが発生します。

## フリー素材の見極め

**外国人モデルの笑顔の写真を貼った瞬間、「テンプレートで作ったサイト」に見えます。**
地域の整体院に、金髪のビジネスマンがハイタッチしている写真は要りません。

判断基準:
- **人物のフリー素材は避ける。** どうしても使うなら、日本人・その業種の現場・演出過剰でないもの
- **モノ・風景・抽象は比較的安全**
- 同じ素材を競合サイトが使っていないか確認する（画像検索で調べられる）
- 有料素材（PIXTA / Adobe Stock）の方が、日本のビジネス文脈に合うものが見つかりやすい。**数千円をクライアントに請求してでも使う価値がある**

**写真がないなら、写真を使わない設計にする**のも一流の判断です。
タイポグラフィと余白と図版だけで作ったページは、悪い写真を貼ったページより確実に良く見えます。

## クライアント支給写真の現実

支給される写真は、だいたい次のどれかです。

- 暗い（店内をスマホで撮っただけ）
- 傾いている
- 解像度が足りない（LINEで送られてきた圧縮済み画像）
- 余計なものが写り込んでいる（段ボール、生活感、他社のロゴ）

**そのまま使わない。** 最低限の補正は制作側の仕事です。
- 明るさ・コントラスト・水平の補正
- トリミングで不要な要素を落とす
- 解像度が足りないものは**使わない**。引き伸ばすとかえって粗が目立つ

補正で救えないなら、正直に伝えて撮り直しを提案してください。「この写真だと、かえって印象が下がります」と言えるのがプロです。

## 撮影指示書の書き方

クライアントに自分で撮ってもらう場合、**「いい感じに撮ってください」は通じません。**
以下のレベルまで具体化します。

```markdown
## 撮影のお願い

### 全体の注意
- 昼間、窓際の自然光で。蛍光灯だけだと黄色くなります
- スマホで構いません。ただし「ポートレートモード」は使わないでください
- 横向き（横長）で撮ってください
- 撮る前に、写り込む範囲の段ボール・私物を片付けてください

### 撮ってほしいもの
1. 店舗の外観（道路の反対側から、看板が読める距離で）
2. 施術室の全景（入口から、部屋全体が入るように）
3. 施術中の様子（モデルは スタッフの方でOK。顔が写らない角度でも可）
4. 院長様のお写真（上半身、背景はなるべく無地の壁）

### あると嬉しいもの
- 使っている道具のアップ
```

**この指示書を出せるかどうかが、単価の差になります。**

## トリミング

- **人物は視線の方向に余白を空ける。** 顔が向いている側を詰めると、窮屈で不安な絵になる
- 頭の上を詰めすぎない / 空けすぎない
- 関節（首・手首・膝）で切らない
- 引きの写真を無理に寄せない。解像度が死ぬ

## 写真の役割を分ける

- **人物写真 = 信頼**（誰がやっているか）
- **モノ・現場写真 = 説明**（何をするのか）
- **抽象・風景 = 雰囲気**（多用すると内容が薄まる）

雰囲気写真だけのページは、何の会社か分かりません。

## 権利（事故ると賠償になる）

- **他社サイトから画像を持ってこない。** 論外です
- フリー素材でも**商用利用可か、クレジット表記が要るか**を確認する
- 人物が写る写真は**モデルリリース**（肖像権の許諾）が必要
- 施設内で撮影した写真は、施設の許可が要る場合がある
- 有名キャラクター・企業ロゴ・アート作品が写り込んでいないか確認する
- お客様の顔を載せるなら、**書面で許諾を取る**

## AI生成画像の扱い

使ってはいけないわけではありません。**偽ってはいけない**のです。

- **AI生成画像を「実際の店舗写真」「実際のスタッフ」として使わない。** これは最も信頼を失う行為です。購入者・来訪者から指摘されれば、返金・通報につながります
- 抽象的な背景・図版としてなら問題は小さい
- 使う場合はクライアントに**必ず事前に伝え、合意を取る**
- 有名キャラクター・実在の人物・商標が生成物に混入していないか確認する
- AI生成画像を「手描きイラスト」として売らない

**判断基準: それが実物だと誤解されたら困るなら、使わない。**

## 実装

- WebP に変換する（JPEG比で3〜4割軽い）
- ファーストビュー以外は `loading="lazy"`
- 適切な解像度で書き出す（4000pxの写真をCSSで縮小して表示しない。読み込みが重いだけ）
- `alt` を必ず書く。**装飾目的なら `alt=""`**（読み上げから除外される）
- 縦横比を指定してレイアウトシフトを防ぐ
