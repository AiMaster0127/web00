# コンバージョン最適化

**CVRを上げるのは、ボタンの色ではありません。** 摩擦を減らし、不安を消すことです。

そして最初に伝えるべき厳しい事実がひとつあります。

## 前提: あなたのページはほぼ読まれていない

読み手は「読む」のではなく「**探している**」。
求めているものが3秒で見つからなければ去ります。離脱の大半はファーストビューで決まります。

だから、**ファーストビュー以外をどれだけ磨いても、CVRは大して動きません。**

## ファーストビュー（ここが8割）

スマホの最初の1画面に、以下が入っているか。

1. **誰向けか**（「自分のことだ」と3秒で分かるか）
2. **何ができるか**
3. **次の行動**（CTAが最初の1画面に見えているか）

よくある失敗: 大きな綺麗な写真とロゴだけがあり、スクロールしないと何の会社か分からない。
**スマホで確認してください。** PCで作ってPCで確認する限り、この失敗には気づけません。

## フォーム: 項目を1つ減らすたびにCVRは上がる

これは最も確実に効く施策です。

**各項目に「これがないと本当に困るか」を問う。** 困らないなら消す。

| 項目 | 判断 |
|---|---|
| 名前 | 要る |
| メールアドレス | 要る |
| **電話番号** | **必須にすると露骨に落ちる。**「電話される」と思われるため。任意にするか、理由を書く |
| 住所 | 見積りに本当に要るのか？ |
| 会社名 | BtoBでも、初回接触では要らないことが多い |
| ご要望（自由記述） | 必須にしない。書けない人が離脱する |
| 性別・年齢 | ほぼ不要。統計目的なら後で聞く |

**必須項目を減らすのが最優先。** 任意項目は残しても害が小さい。

## 不安の除去（見落とされがちで、最も効く）

CVを妨げるのは、たいてい入力の面倒さではありません。**押した後に何をされるかの不安**です。

送信ボタンの直前に置く一行:

> 「しつこい営業のご連絡はいたしません」
> 「その場で概算費用が分かります。契約の義務はありません」
> 「1営業日以内にご返信します」

**この1行の有無で送信率が変わります。** 実装コストはゼロです。必ず入れてください。

同じ発想で、FAQの役割はCV直前の障害の除去です。
「断ったら気まずいのでは」「素人質問でも大丈夫か」——こうした心理的障壁を、FAQで先に潰しておきます。

## 価格を隠すと問い合わせは減る

「価格はお問い合わせください」は、安心のためではなく**離脱の理由**になります。
概算・レンジ・「〇〇の場合は△万円〜」だけでも書いてください。

## CTA

- **ページ内に複数配置する。** 読み手はスクロール位置のどこで決心するか分からない
- **文言を統一する**（「無料で相談する」なら全部それ）
- 動詞で書く。「送信」ではなく「無料で相談する」
- **色より、文言と位置が効きます。** ボタンの色でA/Bテストするのは大抵時間の無駄

## モバイル

- **タップ領域は最低44×44px。** 隣接する要素と8px以上離す
- 親指が届く範囲（画面下部）にCTAを置く。追従バーは有効
- 電話番号は `tel:` リンクにする。タップして即発信できないのは機会損失
- フォームの `inputmode` / `autocomplete` を設定する（数字入力で数字キーボードが出ないだけで離脱する）

```html
<input type="tel" inputmode="numeric" autocomplete="tel">
<input type="email" inputmode="email" autocomplete="email">
```

## 速度

表示が遅いページは、内容を読まれる前に閉じられます。

- 日本語Webフォントのウェイトを絞る（1ウェイト約1.5MB）
- 画像はWebP + `loading="lazy"`
- ファーストビューの画像だけは `lazy` にしない（かえって遅く見える）

## 社会的証明

- 実績・お客様の声は効く。**ただし支給された事実のみ。捏造は絶対にしない**
- 数字は具体的に。「多くのお客様」より「累計412件」
- 顔写真・実名があるほど信じられるが、**許諾を必ず取る**

## A/Bテストについての正直な話

**月間CVが100件を下回るサイトでA/Bテストをしても、統計的に何も分かりません。**
差が出たように見えても、それは偶然です。

小規模サイトでやるべきは、テストではなく**明らかな摩擦の除去**です。

1. ファーストビューで誰向けか分かるようにする
2. フォームの必須項目を減らす
3. 送信前の不安を1行で消す
4. スマホでの操作性を直す
5. 価格を書く

この5つを先にやってください。**A/Bテストはその後、母数が育ってからの話です。**

## 検品の観点

- [ ] スマホの最初の1画面に「誰向けか」「何ができるか」「CTA」があるか
- [ ] フォームの必須項目は最小か。電話番号を安易に必須にしていないか
- [ ] 送信ボタンの前に、不安を消す一行があるか
- [ ] 送信後に何が起きるか書いてあるか
- [ ] CTA文言がページ内で統一されているか
- [ ] タップ領域44px以上、親指の届く位置にCTAがあるか
- [ ] `inputmode` / `autocomplete` / `tel:` リンクが設定されているか
- [ ] 価格情報が何もない状態になっていないか
