# 日本語Web組版

**日本語のWebページが「素人っぽい」と感じられる原因の8割は、色でもレイアウトでもなく組版です。**
欧文用の初期値をそのまま日本語に当てると必ず崩れます。ブラウザの初期値は日本語のために作られていません。

## なぜ欧文の初期値が効かないのか

日本語は全角の正方形に文字が詰まっており、字面が大きく、単語間のスペースがありません。
その結果、欧文と同じ設定にすると「詰まって見える」「どこで切れているか分からない」状態になります。ここを直すだけで、同じデザインが別物に見えます。

## 数値の基準

```css
body {
  font-size: 16px;        /* 16px未満は漢字が潰れる。最低ライン */
  line-height: 1.8;       /* 欧文の1.5では詰まる。1.7〜1.9が読みやすい */
  letter-spacing: 0.04em; /* 日本語は少しだけ開けると締まる。0.02〜0.06em */
}
```

| 項目 | 日本語の基準 | 欧文の感覚で失敗する値 |
|---|---|---|
| 本文サイズ | 16〜18px | 14px（漢字が潰れる） |
| 行間 | 1.7〜1.9 | 1.5（詰まる） |
| **行長** | **1行 35〜45文字** | 制限なし（長すぎて目が戻れない） |
| 字間 | 0.02〜0.06em | 0（詰まって見える） |
| 見出しの行間 | 1.3〜1.4 | 本文と同じ1.8（間延びする） |

**行長は最も見落とされ、最も効きます。** `max-width: 40em` 程度で本文の幅を止めてください。
横幅いっぱいに日本語が流れているページは、それだけで読まれません。

## 約物のアキ（プロっぽさの分水嶺）

`「」『』（）、。` は文字の左右に大きな空白を持っています。放置すると、括弧の周りだけスカスカに見えます。

```css
body {
  font-feature-settings: "palt" 1;  /* プロポーショナル字形。約物のアキを詰める */
}
```

ただし `palt` は全体に効くため、**字間（letter-spacing）とセットで調整**してください。`palt` だけ入れると今度は詰まりすぎます。

## 禁則処理と改行

```css
body {
  line-break: strict;        /* 日本語の禁則を厳格に。「、」が行頭に来るのを防ぐ */
  overflow-wrap: anywhere;   /* ❌ 日本語では使わない。単語の途中で切れる */
  word-break: break-all;     /* ❌ 使わない。「東京都」が「東京/都」になる */
}
```

`word-break: break-all` と `overflow-wrap: anywhere` は日本語を破壊します。
URLがはみ出す等の理由で入れたくなりますが、その要素にだけ限定して当ててください。

### 見出しの改行は意味で切る

日本語の見出しは、ブラウザ任せにすると意味の途中で折れます。

```html
<!-- 意味の切れ目で折る -->
<h1>3ヶ月で<wbr>問い合わせが2倍になった<wbr>理由</h1>

<!-- または、折り返し単位を作る -->
<h1><span class="nowrap">3ヶ月で問い合わせが2倍になった</span>理由</h1>
```
```css
.nowrap { display: inline-block; }
```

## 和欧混植

数字とアルファベットを日本語フォントで表示すると、幅が不自然になります。
**font-family は欧文を先に書く**（先に書いたフォントが優先して使われる）。

```css
body {
  font-family:
    "Helvetica Neue", Arial,           /* 欧文・数字はこちらが拾う */
    "Hiragino Sans", "Noto Sans JP",   /* 日本語はこちら */
    sans-serif;
}
```

## Webフォントの重さ（実装で最も事故る）

**Noto Sans JP は1ウェイトで約1.5MB。** 全ウェイト読み込むと10MB近くなり、体感速度を殺します。
「デザインは綺麗だが遅い」ページの原因はほぼこれです。

対策:

1. **ウェイトを絞る。** 400と700の2つで足りる。300も500も要らない
2. `font-display: swap` を入れる（読み込み中もテキストを表示する）
3. 見出しだけWebフォント、本文はシステムフォント、という割り切りは有効
4. サブセット化（使う文字だけ抽出）を検討する

```css
/* システムフォントで十分な場合の推奨スタック（0KB） */
font-family:
  system-ui, -apple-system,
  "Hiragino Sans", "Hiragino Kaku Gothic ProN",
  "Noto Sans JP", "Yu Gothic", Meiryo, sans-serif;
```

**判断基準**: フォントがブランドの核でないなら、システムフォントで十分です。1.5MBを払う価値があるか毎回問うこと。

## 書体選び

- **ゴシック**: Web本文の基本。小さいサイズでも潰れない
- **明朝**: 品格は出るが、16px以下で潰れる。使うなら本文18px以上、行間広め。見出しだけに使うのが安全
- **縦組み**: Webでは事故る（スクロール方向・選択・アクセシビリティ）。要件がない限り使わない
- 装飾書体は見出しの1箇所だけ。本文に使わない

## チェックリスト

実装したら、この順で確認してください。

- [ ] 本文16px以上、行間1.7〜1.9
- [ ] 1行が45文字を超えていない（`max-width` で止める）
- [ ] 括弧や句読点の周りが不自然に空いていない（`palt`）
- [ ] `word-break: break-all` / `overflow-wrap: anywhere` を全体に当てていない
- [ ] 見出しが意味の途中で折れていない（**スマホ幅で確認**）
- [ ] 数字・英字が不自然に太く/細くない
- [ ] Webフォントのウェイトが2つ以下
- [ ] 375pxで確認した
