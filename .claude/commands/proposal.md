以下の募集要項に対する応募提案文を作ります。

$ARGUMENTS

## 手順

1. 募集要項を読み、**具体的に何を求めているか**を1行で言語化する
2. `docs/pricing.md` を参照して価格帯を決める
3. 以下の型で提案文を書く

## 提案文の型

```
1. 相手の募集文から具体的に拾った一言（要件を読んだ証拠になるもの）
2. 静的ページで終わらせない差別化の一言（フォームDB保存 / 予約 / LINE通知 / 管理画面 など、
   この案件に本当に有用なものだけ）
3. 価格: 機能込みで ¥25,000〜 を下限とする。手数料20%を織り込む
4. 納期
5. 修正回数の上限（標準2回）
```

## 厳守

- **コピペ提案にしない。** 募集要項に一切触れていない提案は即落選する。最低1つは相手の文面から具体を拾う
- **¥19,800の価格競争に参加しない。** 安さで取ると、次も安い案件しか来なくなる
- できないことを「できます」と書かない
- 差別化の一言は、この案件に不要なら無理に入れない（予約機能が要らない募集に予約機能を推すと、読んでいないのがバレる）

## 出力

提案文の本文のみを出力してください。そのままコピーして応募フォームに貼れる状態にすること。
最後に、**この案件を受けるべきかの所見**を2〜3行で添えてください（時給換算が割に合わない、要件が曖昧すぎて危険、等があれば正直に指摘する）。
