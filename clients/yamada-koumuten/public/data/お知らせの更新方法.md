# お知らせの更新方法（クライアント用）

お知らせは、このフォルダの **`news.json`** を編集するだけで、トップページの「お知らせ」欄が自動で切り替わります。
専用の管理画面やログインは不要です。

## 1件追加するには

`news.json` を開き、次の「かたまり」を先頭に足してください（`[` のすぐ下）。

```json
  {
    "date": "2026-08-01",
    "category": "お知らせ",
    "title": "夏季休業のお知らせ",
    "body": "8月13日から8月16日まで休業します。"
  },
```

- **date**: 日付。`西暦4桁-月2桁-日2桁`（例：`2026-08-01`）。新しい日付が自動で上に並びます。
- **category**: 種類。「お知らせ」「施工事例」「休業」など自由（短い言葉で）。
- **title**: 見出し（必須）。
- **body**: 本文。省略しても構いません（その行ごと消してOK）。

## 注意（これだけ守れば壊れません）

- 各項目は **半角のダブルクォート `" "`** で囲む。
- かたまりとかたまりの区切りに **半角カンマ `,`** を入れる。**いちばん最後のかたまりの後ろにはカンマを付けない。**
- 全体は `[` で始まり `]` で終わる。
- 保存したら、サイトを再読み込みして表示を確認してください。
- お知らせを空にしたいときは、中身を `[]` だけにすれば「現在お知らせはありません」と表示されます。

心配なときは、編集前の `news.json` をコピーして控えておくと安心です。
うまくいかないときは、こちらで対応しますのでご連絡ください（保守の範囲で承ります）。
