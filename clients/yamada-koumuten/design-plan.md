# デザイン設計（design-plan.md） — 山田工務店

**1ページの装飾ではなく、5ページで一貫するデザインシステム**として設計する。共通パーツは単一ソース化し、実装で重複を作らない。

---

## 0. 題材から引く（初期値を選ばない）

- 主題: 新潟県三条市の工務店。注文住宅・リフォームを**自社の職人が施工**。社長が相談〜引き渡しまで担当。創業1994年。
- 想定読者: 地元で「ちゃんとした職人に頼みたい」見込み客と、地元で腕を磨きたい求職者。
- このサイトの唯一の仕事: **「この会社なら任せられる」と感じさせ、見積り相談の一歩を踏ませる**。

### 避けるもの（AIが作った感の初期値）
工務店サイトの初期値は「クリーム地＋セリフ見出し＋テラコッタ」。まさに art-direction が挙げる収束パターン#1。
→ **テラコッタを使わない。** アクセントは題材から引き直す。

### シグネチャ要素（1文）
**「墨線（すみせん）」** — 大工が木材に基準を引く一本の細い線を、見出しの下線とセクション境界に使う唯一の構造装置。飾りではなく、この職業の本当の道具から取る。

## 1. カラートークン（アクセントは1色）

| 変数 | 値 | 役割 | なぜこの色か（題材との結びつき） |
|---|---|---|---|
| `--paper` | `#fbfaf7` | ベース背景・面積70% | 漆喰の白壁の白。工務店が実際に塗る素材 |
| `--paper-2` | `#f1ede4` | 交互セクション背景 | 木肌の陰。段差を作り階層を出す |
| `--ink` | `#1d1b18` | 本文・構造・面積25% | 墨（すみ）。大工が引く墨線の色 |
| `--ink-soft` | `#55504a` | 補足テキスト | 墨の淡み。無彩色でなく温かみを持たせる |
| `--indigo` | `#16405c` | **アクセント・面積5%** | **職人の藍。** 作業着・法被・手ぬぐいの紺。信頼と手仕事の色。テラコッタの初期値を避けた選択 |
| `--indigo-deep` | `#122d40` | 反転バンド（CTA帯・フッター） | 藍の濃み。締めの面 |
| `--line` | `rgba(29,27,24,.14)` | 罫線・境界 | 墨線の細い版 |

- アクセントは **CTA・リンク・現在ページ・墨線・小ラベル** のみに使い、面積5%に抑える。だからCTAが目立つ。
- 本文コントラスト: `--ink`/`--paper` は約15:1、`--ink-soft`/`--paper` は約7:1、白/`--indigo` は約8:1。すべて4.5:1以上。
- 反転バンドの白文字は `--indigo-deep` の上。彩度の高い色を大面積に使わない（藍は低彩度）。

## 2. タイポグラフィ（システムフォント優先＝0KB・軽量）

Webフォントは読み込まない。**明朝の品格＋ゴシックの可読性**をシステムフォントで両立する。

```css
/* 見出し：明朝（品格・老舗の手仕事感）。大サイズのみで使うので潰れない */
--font-serif: Georgia, "Times New Roman",
  "Yu Mincho", "游明朝", YuMincho, "Hiragino Mincho ProN", "Noto Serif JP", serif;
/* 本文・UI：ゴシック（可読性）。欧文・数字を先に拾わせる（和欧混植） */
--font-sans: "Helvetica Neue", Arial,
  system-ui, -apple-system, "Hiragino Sans", "Noto Sans JP", "Yu Gothic", Meiryo, sans-serif;
```

| 用途 | サイズ | 行間 | 字間 | 書体 |
|---|---|---|---|---|
| 本文 | 16–17px | 1.85 | 0.04em | sans |
| H1（ページ見出し） | clamp(1.9rem, 5vw, 2.9rem) | 1.35 | 0.02em | serif |
| H2（セクション） | clamp(1.4rem, 3.5vw, 1.9rem) | 1.4 | 0.02em | serif |
| H3（カード等） | 1.15rem | 1.5 | 0.02em | sans(bold) |
| 小ラベル | 0.78rem | — | 0.12em | sans |

- `font-feature-settings: "palt" 1` ＋ `letter-spacing` で約物のアキを締める。
- 本文の**行長は `max-width: 40em`** で止める（1行45文字以内）。
- 見出しはスマホで意味の途中折れを防ぐため `.nowrap`（inline-block）を要所に使う。
- `line-break: strict`。`word-break: break-all`・`overflow-wrap: anywhere` は全体に当てない（URL等の要素のみ）。
- Webフォント不使用のため 1.5MB のロードは発生しない（軽量要件を満たす）。

## 3. 余白・レイアウト

- スペーススケール（8px基準）: 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96 / 128
- セクション縦余白: `clamp(48px, 8vw, 104px)`（セクション間 > 要素間 > 行間 の順に差をつける）
- ページ最大幅: 1080px。本文カラムは 40em。
- 角丸は `3px`（木材・建材の精度感。ゼロだと硬すぎ、大きいと軽い）
- **モバイルを先に描く**（375px基準）。グリッドは 1カラム→2カラム→3カラムで段階的に。

## 4. 共通パーツ定義（単一ソース／各ページにコピペしない）

実装では partials に切り出し、ビルドで各ページへ差し込む（`src/partials/`）。

| パーツ | 内容 |
|---|---|
| ヘッダー | 社名ロゴタイプ（テキスト）＋グローバルナビ＋電話＋「見積り相談」ボタン。PC上部固定 |
| グローバルナビ | トップ／施工事例／会社概要／採用／お問い合わせ。現在ページを `aria-current` で表示 |
| パンくず | トップ以外の全ページ。`ホーム > 現在地`。BreadcrumbList構造化データ付き |
| フッター | 会社情報・ナビ・電話・お問い合わせ導線・コピーライト |
| SP追従バー | 375〜767pxで画面下部に「電話」「見積り相談」を固定。親指で届くCV導線 |
| セクション見出し | 小ラベル＋H2＋**墨線**（下線）の3点セット |
| カード | 施工事例カード・理由カード。影は最小、境界は墨線 |

## 5. ページ別ビジュアル方針

- **トップ**: FVは写真1枚（施工事例＝差し替え前提）＋短いコピー＋CTA。以降、選ばれる理由→事業→事例抜粋→**ご相談の流れ（4ステップ・真に順序があるので番号を使う）**→お知らせ→会社概要抜粋→CTA帯。
- **施工事例**: カードグリッド（写真・種別・エリア・一言）。写真プレースホルダは「写真差し替え」と分かる中立的な図に。
- **会社概要**: 代表挨拶→会社情報テーブル→事業→アクセス。人物写真に依存しない。
- **採用**: 働く環境→募集要項テーブル（給与等は仮置き＋確定要）→応募導線。
- **お問い合わせ**: 電話最優先→フォーム（種別で分岐）→個人情報の一文。

### 番号（01/02/03）の扱い
- **「選ばれる3つの理由」には番号を付けない**（順序ではなく集合。飾りの番号は嘘になる）。
- **「ご相談の流れ」には番号を付ける**（相談→設計→施工→引き渡しは真の順序）。

## 6. モーション

- スクロール時にカード等を**わずかに**フェードアップ（一箇所の演出）。距離8px・200ms程度。
- `@media (prefers-reduced-motion: reduce)` で全アニメーションを無効化。
- 目的のない動きは入れない。

## 7. 品質の床（宣言せず満たす）

375pxから破綻しない／キーボードフォーカス可視（藍のアウトライン）／reduced-motion尊重／本文コントラスト4.5:1以上。

## 8. 出力前の自己批評（art-direction準拠）

1. **無思考で作りそうなものと一致する部分**: 工務店＝クリーム＋セリフ＋テラコッタ。→ アクセントをテラコッタから**藍紺**へ変更し一致を外した。見出しは明朝だが**大サイズ限定**、本文はゴシックで初期値の「全面セリフ」を回避。
2. **3つの初期値パターンに寄っていないか**: #1（クリーム＋セリフ＋テラコッタ）に寄りかけたが、色と書体運用で回避。#2・#3は非該当（罫線は墨線1本の意味ある使用に限定し、ブロードシート化しない）。
3. **各色・書体になぜを言えるか**: 漆喰＝paper／墨＝ink／藍＝職人の作業着／明朝＝手仕事の品格。すべて題材と結びつく。
4. **アクセントは1色か**: 藍1色。2色目を足さない。
5. **シグネチャは1文で言えるか**: 「墨線 — 大工の基準線を見出しとセクション境界に使う唯一の構造装置」。
6. **削れる装飾は残っていないか**: 影を最小化、装飾番号を排除、Webフォントを排除。取るリスクは「明朝×藍」1点に集約。
