## 2. ローカルでの確認・再ビルド方法

共通パーツ（ヘッダー等）を直したら、`public/` を再生成します。

```bash
cd clients/yamada-koumuten
node src/build.js              # public/ を再生成（Node標準のみ・追加インストール不要）
# 表示確認（どちらでも可）
python3 -m http.server 8000 --directory public   # → http://localhost:8000
```

> お知らせ（news.json）はビルド不要。編集して保存し、ブラウザを再読み込みするだけで反映されます。

## 3. デプロイ手順（クライアント向け）

`public/` フォルダの中身をそのまま公開するだけです。サーバサイド処理は不要。

- **Netlify / Cloudflare Pages / Vercel** のいずれか（静的ホスティング）。
  - 公開ディレクトリ（publish directory）を `public` に指定。ビルドコマンドは `node src/build.js`（または不要）。
  - ドラッグ&ドロップで `public` の中身を上げるだけでも公開できます。
- 独自ドメインは**新規取得が必要**（未取得）。取得後、ホスティング側でドメインを接続。

### フォーム送信先の設定（例：Formspree）
1. Formspree で無料アカウント作成 → フォーム作成 → エンドポイントURLを取得。
2. `src/pages/contact.html` の `action="https://formspree.io/f/REPLACE_WITH_ENDPOINT"` を実URLに変更 → `node src/build.js`。
3. 送信すると `thanks.html` に遷移。届いたメールで受信確認。
- 実装済みのスパム対策：ハニーポット（`_gotcha`）。入力検証・必須チェックはJS側で実装済み。
- ⚠️ **チェックリスト🔴「フォームが実際に送信でき、送信先に届く」は、エンドポイント設定後に要実送信テスト**（現状はデモのため未達）。
