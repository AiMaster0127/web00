# デザイン設計 — 海老勢 HP

## コンセプト

**「壁の短冊お品書きを、そのままWebの構成要素にする」**

海老勢は駅前の「わいわい肴屋」。澄ました割烹ではなく、市場で仕入れた魚を短冊のお品書きで出す店。
デザインの源泉は、居酒屋の現場の語彙から引く: **短冊（お品書き）・暖簾の藍・提灯の朱・青海波（店名の「海」）**。

- シグネチャ要素: **短冊モチーフ**（メニュー項目・セクションラベルを短冊状のカードで組む。縦書きの一文字ラベル「肴」「宴」「昼」を各セクションの目印にする）
- 大胆さはここ一箇所に使い、他は余白と文字の精度で静かに保つ

## 「AIが作った感」の回避（自己批評）

初期値パターンとの照合:
1. クリーム背景+セリフ+テラコッタ → **回避。** ベースはクリームではなく白（#FBFAF7）。アクセントはテラコッタ（くすんだ橙）ではなく提灯の朱（赤側・暗め #C73A2A）。題材（暖簾・提灯・短冊）から引いた選択
2. ほぼ黒+アシッドグリーン → 非該当
3. ブロードシート風 → 非該当。罫線はヘアラインでなく、短冊の「面」で区切る

## カラートークン

| トークン | 値 | 由来・用途 | 面積 |
|---|---|---|---|
| `--ink` | `#1B3246` | 濃藍（暖簾・半纏の藍）。見出し・本文・構造 | 25% |
| `--paper` | `#FBFAF7` | 白（お品書きの白紙・白木）。背景 | 70% |
| `--accent` | `#C73A2A` | 朱（提灯・盃）。CTA・強調のみ | 5% |
| `--ink-soft` | `#46586A` | 藍がかったグレー。補足テキスト（コントラスト4.5:1以上） |  |
| `--paper-dim` | `#F2EFE9` | セクション交互背景・短冊の地 |  |
| `--indigo-deep` | `#122435` | フッター・写真スロットの地 |  |

- アクセントは朱の1色のみ。2色目を足さない
- 本文 `--ink` on `--paper` はコントラスト比 約12:1、`--ink-soft` は約6:1
- 朱ボタンの文字は白（約5.1:1）

## タイポグラフィ

| 用途 | 書体 | 補足 |
|---|---|---|
| 見出し・屋号 | **Shippori Mincho B1（700のみ）** | Webフォント1ウェイトに絞る（`font-display: swap`・Google Fonts） |
| 本文・UI | システムゴシック（0KB） | `system-ui, "Hiragino Sans", "Noto Sans JP", "Yu Gothic", Meiryo, sans-serif`（欧文は`system-ui`が先に拾う） |

- 本文: 16px以上 / `line-height: 1.9` / `letter-spacing: 0.04em` / `font-feature-settings: "palt" 1` / `line-break: strict`
- 行長: 本文は `max-width: 40em` で止める
- 見出し行間: 1.3–1.4。改行は `<br>`・`.nowrap` で意味の切れ目に置く（375pxで確認）
- 縦書きは装飾ラベル（一〜二文字の短冊）だけに限定。本文では使わない

## 余白スケール

`--sp-1: 8px / --sp-2: 16px / --sp-3: 24px / --sp-4: 40px / --sp-5: 64px / --sp-6: 104px`

- セクション間（--sp-6） > ブロック間（--sp-4〜5） > 要素間（--sp-2〜3） の差を明確に
- モバイルを先に設計し、迷ったら余白は広い方を取る

## 共通パーツ仕様

- **ヘッダー**: 白地・上辺に藍の細帯。屋号（縦積みテキストロゴ: 「わいわい肴屋」+「海老勢」）+ ナビ4項目 + 朱の電話ボタン。モバイルはハンバーガーではなく横スクロールしない4項目簡易ナビ（項目が少ないため畳まない）
- **モバイル追従バー**: 画面下固定。「電話をかける」（朱）/「ネット予約」（藍枠）。44px以上・8px間隔
- **CTAブロック（全ページ下部）**: 藍地に青海波の微細テクスチャ。営業時間・定休日を併記し、電話とネット予約の2択
- **短冊カード**: メニュー項目・コース表示の基本ユニット。上辺に藍の帯、価格は右端タブ位置
- **パンくず**: 下層ページ冒頭。`--ink-soft`
- **写真スロット**: 支給待ちの間は `--indigo-deep` 地 + 青海波 + 「写真が入ります（外観／刺身盛り 等）」の白抜きラベル。実写と誤解される画像（AI生成・フリー素材の料理写真）は置かない

## モーション

- ヒーローの見出しフェードイン1箇所のみ（0.6s / ease-out）
- スクロール連動・パララックスは使わない
- `prefers-reduced-motion: reduce` で全て無効化

## ページ別ワイヤー（モバイル基準）

### / トップ
1. ヒーロー: 青海波の白地に大見出し（屋号+一言定義）+ 営業時間・定休日の即答帯 + CTA2択
2. 「海老勢の決めごと」3点（市場買い付け／個別盛り／コシヒカリ・冷凍野菜不使用）— 短冊3枚
3. 宴会への導線（個別盛りの一言 + /party/ へ）
4. お品書きダイジェスト（短冊数枚 + /menu/ へ）
5. アクセス要約（駅徒歩1分・地図リンク + /access/ へ）
6. 共通CTAブロック

### /menu/
昼（ランチ）→ 夜（肴）→ ドリンクの3セクション。各セクションに縦書き短冊ラベル「昼」「肴」「酒」。価格未支給のため「—」表示

### /party/
ヒーロー（個別盛りの価値提訴）→ 宴会の不安つぶし3点（個別盛り/飲み放題4名〜/駅前）→ コース枠（内容未支給・枠のみ）→ 幹事向けFAQ → 予約導線

### /access/
NAP即答（住所・電話・営業時間表）→ 地図 → 行き方・駐車場 → 姉妹店「海茶屋」→ 会社概要

### /reserve/
電話（主・番号大きく）→ ネット予約（ホットペッパー）→ 宴会相談フォーム（項目最小・不安除去の一文つき）

## 実装注意

- ファーストビューに `loading="lazy"` を使わない（現状画像なし・将来差し替え時の注意）
