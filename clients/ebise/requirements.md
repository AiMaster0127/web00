## 1. 目的と成果指標

- 目的: **集客**（クライアント原文）
- 想定CV（優先順位は★仮定）
  1. **宴会・コースの予約電話**（単価が高く、個別盛り・飲み放題という明確な差別化がある）
  2. 夜の来店（今夜どこで飲むか検討中の人）
  3. ランチの来店（駅前・カレーラーメン・定食）
- CV手段: `tel:` リンク（主）、ホットペッパーのネット予約リンク（副）、宴会相談フォーム（補助）

## 2. ターゲット

- 三条市・燕三条エリアで宴会の幹事を任された人（会社・グループ、4名〜）
- 東三条駅周辺で夜に飲む店・昼に定食を探している人（検索・地図経由）
- 指名検索「海老勢」で営業時間・定休日を確かめに来る既存客

## 3. サイト種別・規模

- 店舗サイト 6ページ + 404（トップ / お品書き / ご宴会 / 店舗案内 / ご予約・お問い合わせ / プライバシーポリシー）
- ★お知らせ・ブログは作らない（更新主体が未確認。更新されない空ページは信頼を毀損するため）

## 4. 更新・CMS

- ★クライアントによる自己更新は想定しない → **静的HTML**（CMSなし）
- メニュー・価格の改定は制作側で更新代行（保守契約の提案対象）

## 5. 既存サイト（リニューアル扱い）

- 既存: `ebise.jp`（http・海老勢/海茶屋の共通サイト）
- 判明している旧URL: `/` `/access.html` `/ebise_menu.html` `/ebise_corsemenu.html`
- **公開前に全URLの洗い出しと301対応表の完成が必須**（サーバーアクセス取得後）。対応表ドラフトは `sitemap.md`
- ドメイン・サーバー管理者: **不明（要確認・最重要）**
- ★新サイトも `ebise.jp` を継続利用と仮定（canonical・sitemap.xml はこの前提）
