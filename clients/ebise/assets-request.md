# 素材のお願い — 海老勢 HP

> クライアントにそのまま送れる形。写真スロット（サイト内の紺色の枠）に入る素材の依頼書。

## お借りしたいデータ

1. **ロゴデータ**（あれば）: ai / svg / png のどれでも。なければ看板・暖簾がよく写った写真でも構いません
2. **メニューと価格の一覧**: 手書き・ExcelどれでもOK。宴会コースは「コース名・品数・料金・飲み放題の条件」
3. 過去のチラシ・パンフレットのデータ（あれば）

## 撮影のお願い（スマホで構いません）

### 全体の注意

- なるべく昼間、窓からの光がある時間帯に。蛍光灯だけだと黄色っぽくなります
- 「ポートレートモード」は使わず、**横向き（横長）**で撮ってください
- 撮る前に、写り込む範囲の段ボール・伝票・私物を少しだけ片付けてください
- 同じカットを2〜3枚ずつ撮っていただけると、選べて助かります

### 撮ってほしいもの（優先順）

1. **店舗の外観**: 東三条駅の改札側から、看板が読める距離で（昼と、灯りのついた夕方の2回あると最高です）
2. **宴会コースの個別盛り**: 1人前のお膳を、正面と少し上からの2カット
3. **刺身盛り**: 盛り付け直後を、寄りで
4. **店内の全景**: 入口から、席全体が入るように
5. **カレーラーメン**: 湯気があるうちに、麺を箸で持ち上げなくてOK
6. **調理場の様子**: 手元だけでも（顔出しNGでも大丈夫です）

### あると嬉しいもの

- 市場での買い付けの様子（1枚あるだけで「毎日市場で買い付け」に説得力が出ます）
- 大将・スタッフの方のお写真（顔出しの可否もあわせて教えてください）

## お約束

- いただいた写真は明るさ・傾きをこちらで補正してから使います
- 写り込んだお客様のお顔など、公開に不都合な部分は加工または不使用とします
- **フリー素材やAI生成の料理写真は使いません。** 実物の写真だけでサイトを作ります
