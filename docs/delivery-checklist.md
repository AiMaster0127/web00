# 納品前チェックリスト

**これを通していないものは納品しない。**
AI生成コードはエラーハンドリングが抜けやすく、動作確認は必ず自分で行う。

---

## 🔴 これがあると納品不可

- [ ] APIキー・パスワード・DB接続情報がリポジトリに含まれていない
      `grep -ri "api_key\|apikey\|password\|secret\|token" --exclude-dir=.git .`
- [ ] クライアントの実データ（実在の個人情報）が混入していない
- [ ] `noindex` が本番に残っていない
- [ ] `robots.txt` で全体をブロックしていない
- [ ] フォームが実際に送信でき、送信先に届く
- [ ] **【リニューアル時】301リダイレクトが漏れなく設定されている**
- [ ] 375px（iPhone SE相当）で表示が破綻しない
- [ ] 要件定義にあるものが全て実装されている

## 法務

- [ ] 効果効能の断定がない（薬機法）※医療・健康・美容案件
- [ ] 根拠のないNo.1・最安値表記がない（景表法）
- [ ] 特商法表記がある（販売・申込がある場合）
- [ ] お客様の声・実績が捏造されていない（支給された事実のみ）
- [ ] 他者の著作物（ロゴ・画像・文章）を無断使用していない
- [ ] 使用画像のライセンスを確認済み
- [ ] 【採用ページ】性別・年齢による募集制限がない

## 技術

- [ ] 全ページに固有の `title` / `meta description`
- [ ] OGP設定
- [ ] `sitemap.xml` / `robots.txt`
- [ ] 構造化データ（企業・店舗なら Organization / LocalBusiness）
- [ ] リンク切れ・画像切れなし
- [ ] alt / label / 見出し階層
- [ ] キーボードフォーカスが見える
- [ ] `prefers-reduced-motion` 尊重
- [ ] コントラスト比 4.5:1 以上
- [ ] 画像は WebP + lazy loading
- [ ] 日本語Webフォントのウェイトを絞ってある
- [ ] 【フォームあり】CSRF対策・レート制限・サニタイズ
- [ ] 【CMS】管理画面URL変更・強固なパスワード・自動更新設定

## ビジネス

- [ ] `delivery.md` に「今回やっていないこと」を明記した
      ※スコープ外の明示は、後の揉め事とタダ働きを防ぐ最大の防御
- [ ] クライアントが自分でデプロイ・更新できる手順書がある
- [ ] **保守・追加機能の提案を1つ入れた**（ストック収益の入口。毎回サボらない）
- [ ] 修正回数の残数をクライアントに伝えた

---

## 納品時に必ず添える一言

> 「公開後の更新や、機能の追加（予約フォーム・アクセス解析など）も対応できます。
> 月次の保守（更新・バックアップ・不具合対応）は月◯円で承っています。」

**LP/HP制作はフロー型。保守契約を取らない限り、稼働を止めた瞬間に収入がゼロになる。**
