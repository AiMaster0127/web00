# 料金の考え方

## 前提: ¥19,800 の価格競争には参加しない

クラウドソーシングのLP案件は「静的ページを作れる人」で飽和している。
そこで戦うと時給が崩壊し、次も安い案件しか来なくなる。

**戦い方は「安さ」ではなく「静的ページで終わらせないこと」。**
LP + フォームDB保存 + 管理画面、LP + 予約連携、LP + LINE通知 —— これらをセットで出せる個人はまだ少ない。
機能がある分、価格に説得力が生まれる。

## 手数料を必ず織り込む

クラウドソーシングは約20%、ココナラは約22%が引かれる。
**¥25,000で受注 → 手取り約¥20,000。** 単価設定の時点で織り込まないと、時給換算で消耗する。

直接契約なら手数料0%。実績が貯まったら直接契約へ移行するのが収益改善の本丸。

## 見積り時に必ず明記する

- **修正回数の上限**（標準2回。無制限にすると永久に終わらない）
- スコープ外（何を含まないか）
- 素材（写真・原稿）を誰が用意するか
- 公開作業を含むか
- 追加料金が発生する条件

## 判断基準

**時給1,500円を下回る案件は断る。**
1件あたりの作業時間を事前に見積もり、手数料を引いた手取りで割って判断すること。

最初の数件は実績作りとして受けてもいいが、**3ヶ月目以降も安い案件を受け続けると、そこから抜けられなくなる。**

## 単価を上げる順序

```
実績0件   → 提案型（クラウドワークス/ランサーズ）で ¥25,000〜35,000
実績3件   → ココナラ出品を追加。評価が検索順位を作る
実績5件〜 → 直接営業 / 紹介。手数料0%で ¥50,000〜
並行      → 保守契約を積む。ここだけが稼働と無関係に積み上がる
```
