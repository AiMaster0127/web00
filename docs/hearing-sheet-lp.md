# ヒアリングシート【LP用】

> クライアントにそのまま送れる形。専門用語を避け、選択肢を添えて聞く。
> **相手は考えるのが面倒。** 自由記述で聞くほど返答率が下がるので、選ばせる形にする。
>
> HP（複数ページのサイト）案件では `hearing-sheet-hp.md` を使うこと。**聞くことが違う。**

---

## LPで最初に潰すべきこと

LPは **「1ページで、1つの行動を取らせる」** ための道具です。会社案内ではありません。

- **CVが1つに絞れないLPは、必ず失敗します。** ここが決まらないうちは見積りを出さない
- **流入元が決まらないと、作るものが決まりません。** 広告なのか検索なのかSNSなのかで、ページの中身が変わる

この2つが未確定のまま着手しないでください。

---

## 1. 目的（最重要）

- **このページを見た方に、最終的に何をしてほしいですか？（1つだけ選んでください）**
  - [ ] 電話で問い合わせ
  - [ ] フォームから問い合わせ
  - [ ] LINE登録
  - [ ] 予約
  - [ ] 資料請求・ダウンロード
  - [ ] 購入
- 複数選びたくなった場合 → **どれが一番大事ですか？**
  ※ここを1つに絞れないと成果が出ません。理由も含めてご相談させてください
- 今、集客で一番困っていることは何ですか？
- 現状、月に何件くらい問い合わせがありますか？

## 2. 流入元（ここでページの作りが変わる）

- **このページには、どこから人が来る予定ですか？**
  - [ ] Web広告（リスティング / SNS広告）
  - [ ] Instagram・X などのSNSのプロフィールリンク
  - [ ] Google検索
  - [ ] チラシ・名刺のQRコード
  - [ ] まだ決めていない
- 広告を出す場合、**月の予算はどのくらいですか？**
- 広告を出す場合、**誰が運用しますか？**（クライアント / 他社 / 未定）

> 📌 **制作側の判断メモ**
> - 広告流入 → SEOは不要。CVR最優先。表示速度が命
> - 検索流入 → LPだけでは順位が付かない。記事やHPが別途必要になる旨を先に伝える
> - SNS流入 → スマホ100%前提。ファーストビューだけで決まる
> - 「まだ決めていない」→ **ここを決めずに作ると、作り直しになる。** 最優先で詰める

## 3. ターゲット（1人に絞る）

- どんな方に来てほしいですか？（年齢・性別・地域・職業・状況）
- **その方は、今どんなことで困っていますか？**
- その方が、依頼をためらう理由は何だと思いますか？
- 逆に、**来てほしくないお客様**はいますか？

> LPは「みんな向け」に書くと誰にも刺さりません。**たった1人を想定して書きます。**

## 4. 訴求（ここが書けないとLPは書けない）

- 同業他社ではなく、御社を選ぶ理由は何ですか？
- **実績を数字で教えていただけますか？**（年数 / 件数 / リピート率 / 満足度）
- お客様から、よく言われることは何ですか？
- 他社がやっていなくて、御社だけがやっていることはありますか？
- 失敗談や、正直に言えるデメリットはありますか？
  ※これが書けるLPは信用されます

## 5. オファー（CVのハードルを下げる材料）

- **無料で提供できるものはありますか？**（無料相談 / 無料見積り / お試し / 資料）
- **キャンペーンや期間限定の条件はありますか？**
- 価格は掲載できますか？（できる / 概算なら可 / 出せない）
  ※価格が全くないページは、問い合わせが減ります

## 6. 掲載内容

- 必ず載せたいものは？（ロゴ / 電話番号 / 営業時間 / 地図 / 料金 / 特商法表記）
- 載せたくないものはありますか？
- 競合や、参考にしたい他社のページはありますか？（URL）

## 7. 素材 ★揉めやすい

- **写真はご用意いただけますか？**（あり / なし / 一部）
  ※なしの場合、有料素材の購入費（数千円）または撮影が必要になる旨をこの場で伝える
- ロゴのデータはありますか？（ai / svg / png / 名刺しかない）
- **原稿はどちらが書きますか？**（クライアント / こちら）
  ※「いい感じに書いておいて」＝こちらが書く、の意味。工数として見積もる
- お客様の声を載せる場合、**掲載の許可は取れていますか？**

## 8. 機能

- お問い合わせフォームは必要ですか？
- **送信された内容は、メールで届けば十分ですか？　それとも一覧で見られる管理画面が必要ですか？**
  ※ここが単価の分かれ目。管理画面まで作れることを伝える
- LINE通知・予約・決済は必要ですか？
- **広告の成果を計測する設定は必要ですか？**（GA4 / 広告のコンバージョンタグ）
  ※広告を回すなら必須。ないと費用対効果が測れません

## 9. 公開まわり

- ドメイン・サーバーはお持ちですか？（あり / なし / わからない）
- 公開作業もこちらで行いますか？
- **このページは、いつまで公開しますか？**（常設 / キャンペーン期間のみ）

## 10. 条件 ★必ず握る

- **納期はいつまでですか？** その日付の理由はありますか？（広告開始日など）
- ご予算はどのくらいでお考えですか？
- **修正は何回まででお願いできますか？**（標準2回）
- **最終的に決めるのはどなたですか？**
  ※決裁者が別にいると、修正が無限に増える
- 「こういうのは嫌だ」というイメージはありますか？

## 見積り前に必ず確定させる6項目

これが未確定のまま着手すると、ほぼ確実に無償の追加作業か作り直しが発生します。

1. **CVが1つに絞れているか**
2. **流入元（広告 / 検索 / SNS）**
3. 写真素材を誰が用意するか
4. 原稿を誰が書くか
5. 修正回数の上限
6. 最終決裁者は誰か

## 危険信号

以下が出たら、見積りを上げるか、条件を書面化してから受けること。

- 「CVは問い合わせも予約も購入も全部」→ 絞れていない。成果が出ず、こちらの責任にされる
- 「とりあえずかっこいい感じで」→ 判断基準がない。修正が無限化する
- 「写真は適当にいい感じのを入れて」→ 素材支給なし。工数に入れる
- 「上の者に確認します」が初回から出る → 決裁者が別。修正が増える前提で見積もる
- 「集客はLPを作れば何とかなると思って」→ 流入設計がない。**LPを作っても人は来ないと先に伝える**
